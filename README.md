# 🌱 GreenAlert — Landing Page

> **Plataforma cívico-digital y colaborativa para la detección, clasificación y mitigación de problemas ambientales urbanos en tiempo real.**

### Estructura del Proyecto

El repositorio sigue una arquitectura organizada y desacoplada para proyectos frontend:

```text
GreenAlert-Landing-Page/
├── README.md                      # Documentación completa del proyecto
├── favicon.ico                    # Favicon principal en la raíz
├── public/                        # Carpeta principal del proyecto y archivos HTML
│   ├── favicon.ico                # Favicon para el despliegue del sitio público
│   ├── index.html                 # Página de aterrizaje (Landing Page) interactiva
│   └── assets/                    # Carpeta de recursos y activos multimedia
│       ├── styles/                # Hojas de estilo en cascada (.css)
│       │   └── styles.css         # Estilos globales, diseño responsive y tema
│       ├── images/                # Recursos gráficos e imágenes (.jpg, .png, etc.)
│       │   └── logo.jpg           # Logotipo oficial de GreenAlert
│       └── scripts/               # Lógica interactiva en JavaScript (.js)
│           └── main.js            # Controladores del mapa, modales, IA simulada y auth
```
